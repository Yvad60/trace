# POC — Reconciliation: Results

**Verdict: confirmed.**
Most of the used providers (banks and mobile money) provides statements in PDF and CSV format, which can be parsed and reconciled with the SMS transactions.

**MTN Mobile Money**
The mobile money provider provides statements in only PDF format

Available information:

- Transaction ID
- Status
- Transaction type
- Date and time
- From/to (sender/receiver)
- Amount
- Fee
- Balance after transaction

**Bank of Kigali**
The bank provides statements in CSV format.

Available information:

- Account
- Currency
- Reference
- Date
- Credit/Debit indicator
- Balance after transaction

**Equity Bank**
The bank provides statements in PDF and CSV format.

Available information:

- Transaction details (date, amount, type, description)
- Payment reference
- Value date
- Credit(Money In)/debit(Money Out) indicator
- Balance after transaction

**I&M Bank**
I&M Bank doesn't natively provide statements from their online portal, manual call to the bank is required to get the statements. The bank provides statements in PDF format.

Available information: N/A
